Sistema de diagnóstico médico con lógica de primer orden usando
[aima-python](https://github.com/aimacode/aima-python) (`FolKB`, `fol_bc_ask`).

| Archivo | Qué es |
|---|---|
| `mi_diagnostico.py` | Archivo de trabajo: el ejercicio hecho paso a paso, con las correcciones del tutor |
| `diagnostico_entrega.py` | Versión final, limpia y comentada (la que aparece en el documento) |
| `entrega/` | Documento entregado en PDF |

El historial de commits muestra el proceso completo: qué escribí yo en cada paso y qué
añadió el asistente de IA que usé como tutor (esos commits lo indican en el título).

## Ejecutarlo

Con aima-python instalado en un entorno virtual (`pip install -e .` dentro del repositorio de aima):

```bash
python diagnostico_entrega.py
```
